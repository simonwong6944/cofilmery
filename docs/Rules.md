# CoFilmery Rules（內容與語體規則）

> 本文件管「內容／語體／紅線」:交畀開發者前必讀,開發者只准跟本文件,任何改動須產品負責人批准。
> 與 SOP-workflow.md（流程）、SOP-modular.md（結構）、Architecture.md（設計意圖）並行。
> 本檔屬「狀態類」:可編輯,但每次改動須喺文件底「修訂記錄」加一行。

## 一、兒童安全紅線（不可妥協）

- 嚴禁生成任何性化未成年人、或針對未成年人嘅色情／曖昧內容。
- 生成角色若涉及未成年人設定,一律唔准配任何情色、暴露、挑逗描述。
- 若用戶要求偏向上述紅線,拒絕並唔提供任何規避方法。

## 二、內容語體

- 預設語體:貼近香港用戶,繁體中文為主,語氣自然、簡潔。
- 生成劇本／story card 時,保持題材適齡、唔美化違法或自我傷害行為。
- 避免以刻板印象作賣點嘅內容。

## 三、密鑰與安全

- 所有 API key 一律入 Cloudflare env secret,唔准硬編碼、唔准出現喺前端程式碼或 repo。
- 前端只可經後端 `/api/ai/*` proxy 呼叫模型,唔可直連 provider 帶 key。

## 四、可配置參數

- 積分（credit）、時限、poll 次數／間隔、模型字串等可配置參數,一律入 config／registry,唔准散落硬編碼。
